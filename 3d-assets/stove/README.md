# 📂 Folder Aset 3D Kompor Modern
Folder ini dibuat otomatis untuk merapikan seluruh aset, berkas Blender, dan hasil ekspor proyek kompor 3D interaktif Anda. Dengan struktur ini, Anda dapat mengelola progres tugas Anda dengan sangat teratur.

---

## 📁 Struktur Folder yang Direkomendasikan
Silakan gunakan pembagian folder di bawah ini di dalam komputer Anda agar tidak berantakan:

1.  **`blender/`**
    *   Tempat menyimpan berkas Blender Anda (misal: `kompor_modern_v1.blend`).
    *   Simpan file `.blend` baru Anda di sini setelah melakukan *blocking*.
2.  **`references/`**
    *   Tempat menyimpan gambar-gambar contoh kompor induksi/gas dari internet untuk panduan pemodelan Anda.
3.  **`exports/`**
    *   Tempat menyimpan hasil ekspor model 3D (seperti format `.gltf` atau `.glb`) yang siap dimasukkan ke website portofolio Anda.
4.  **`renders/`**
    *   Tempat menyimpan screenshot progres (Fase 1 - 4) yang siap Anda kirimkan ke dosen Anda.

---

## 🚀 Langkah Selanjutnya untuk Anda
1. Buka Blender.
2. Buat file baru, lalu lakukan **Fase 1: Langkah 1 & 2** (mengubah ukuran kubus menjadi $80\text{ cm} \times 50\text{ cm} \times 6\text{ cm}$ dan me-*apply scale*).
3. Simpan file Blender tersebut ke dalam folder ini dengan nama:
   `3d-assets/stove/blender/kompor_modern_blocking.blend`
